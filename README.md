# 🚗 Sistema de Gestão de Veículos (CRUD Full Stack)

Este é um projeto **Full Stack** desenvolvido para gerenciamento de estoque de veículos. O sistema permite cadastrar, listar, editar e excluir veículos, além de oferecer um dashboard financeiro e busca em tempo real.


## 📋 Funcionalidades

- **CRUD Completo:** Criação, Leitura, Atualização e Exclusão de veículos.
- **Dashboard Financeiro:** Exibe automaticamente o total de veículos e o valor somado do estoque.
- **Busca em Tempo Real:** Filtro instantâneo por marca ou modelo.
- **Validação de Dados:** Backend impede cadastro de preços negativos ou campos vazios.
- **Segurança:** Implementação de `Helmet` para proteção de cabeçalhos HTTP.
- **Responsividade:** Layout adaptável para dispositivos móveis.

## 🛠️ Tecnologias Utilizadas

### Frontend
- **HTML5 & CSS3** (Layout moderno e responsivo)
- **JavaScript ES6+** (Consumo de API com `fetch`, manipulação de DOM)

### Backend
- **Node.js**
- **Express.js** (Servidor API RESTful)
- **Mongoose** (Modelagem de dados)
- **Helmet & Cors** (Segurança)

### Banco de Dados
- **MongoDB** (NoSQL)
